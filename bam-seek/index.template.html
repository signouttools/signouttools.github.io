Calculation settings and IGV reference

A reference is needed only for IGV sequence/mismatch display. Choose the same reference assembly as the BAM. IGV windows use first-of-pair strand colors, paired display, base sorting, and no downsampling. Windows are temporary; reopen them from a result after a reload.

Phasing findings

Direct molecular linkage only. AB = ALT/ALT, Ab = ALT/REF, aB = REF/ALT, ab = REF/REF. Unsequenced insert gaps do not establish linkage.

Dev local phasing (experimental)

Rare markers support cis through repeated positive co-occurrence. Common markers may support trans through opposite haplotypes. Marker absence and target REF alone carry no phase meaning.

Comparison narrative

Draft wording assumes the Current and Historical variant boxes contain reported calls from the same patient. Review the wording against assay thresholds, coverage and the displayed evidence before use. Variants in Both boxes are excluded.
